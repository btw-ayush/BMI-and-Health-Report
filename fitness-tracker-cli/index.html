A Python command-line app that calculates BMI, daily calories and water intake, then keeps a history so you can see progress. Try the same calculations here.

Three modules, one workflow

Health metrics

Turns age, sex, height, weight and activity into BMI, BMR (Mifflin-St Jeor), maintenance calories, water intake and a healthy weight range.

Classification and advice

Sorts BMI into WHO categories, sets a calorie target, colour-codes the result and gives suggestions matched to the category and activity level.

History and progress

Saves every assessment to a local JSON file. View, annotate or delete records, then get a report of weight change, trend and average BMI.

Built to be reliable

100%offline, data stays local
  • Every input is validated and re-prompted, and you can type cancel at any prompt.
  • Saves are atomic, and a corrupt history file is backed up instead of lost.
  • Events and errors go to a rotating log file.
